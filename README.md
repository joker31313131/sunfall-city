Sunfall City is an original open-world crime game built with plain JavaScript and Canvas 2D — no libraries, no network, everything drawn and synthesised in code. You play Mara Voss, a driver new in town, stealing cars across a sunset-soaked procedural city, dodging a five-star wanted level, and running five linked jobs for her fixer Rook. Traffic, pedestrians, police chases, shootouts, explosive barrels, shops, a full minimap and save games are all in there.

## Run it

Start the little dev server from the repo root:

```sh
node serve.ts
```

then open http://localhost:8080 in desktop Chrome and press New Game. WASD moves and drives, E interacts and steals cars, the mouse aims and clicks shoot.
